# Intelligent Course Recommendation and Guidance System (ICRGS)

ICRGS is a demo web application exploring how engineering students can plan their academic journey through interactive course recommendations, prerequisite mapping, and career pathway exploration.

## Features

- Multi-department course exploration across eight engineering disciplines.
- Interactive curriculum and prerequisite visualization.
- Rule-based course recommendations based on academic progress and career interests.
- What-If academic scenario simulation.
- Academic progress dashboards and data visualization.
- Local profile persistence and PDF portfolio export.

## Technology Stack

- HTML, CSS, and JavaScript
- React 18
- Tailwind CSS
- Recharts
- SVG visualizations
- LocalStorage

Developed with assistance from Google Antigravity.

## Project Status

This is an educational demo prototype. The included curricula and academic calculations are illustrative and must not be treated as official university regulations or as a substitute for academic advising.

The application uses third-party libraries loaded through CDNs and requires an internet connection for those dependencies.

## Running Locally

1. Download or clone this repository.
2. Open `index.html` through a local web server or a compatible browser.
3. Ensure the external CDN dependencies are accessible.

## Disclaimer

ICRGS is intended for demonstration and learning purposes. Verify course requirements, credits, prerequisites, and graduation criteria with the relevant institution before making academic decisions.
